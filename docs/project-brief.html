Local LMS
Content Generation

We are building a local AI system that turns documents into teaching materials for a learning management system (LMS). Pretrained Qwen powers agents that find evidence, draft and revise content. Instructors approve the results. No model training or fine-tuning is required.

4 students  ·  15 weeks  ·  7 September–18 December 2026  ·  Prototype and evaluation

What the system will do

  1. 1 · UploadPDF, Word, slides
  2. 2 · Find evidenceSearch source text
  3. 3 · Plan courseInstructor approves
  4. 4 · Create lessonsReview and edit
  5. 5 · ExportSlides, video, LMS

Our contribution is the agentic authoring workflow: source-grounded planning, lesson creation and review. Uploaded documents supply evidence through retrieval (RAG); model weights stay unchanged.

How we will deliver it

Build one complete course workflow using pretrained models, then measure whether agent decisions improve it. The revised 15-week plan replaces training work with agent integration and evaluation; phases overlap.

Proposed delegation across four students

A–D are workstream labels; student names are to be assigned. Each owner builds the relevant backend and interface, with peer review.

ADocuments and grounding

Own parsing, search tools, citation checks and retrieval tests. Give agents project-scoped evidence with stable references.

BPlanning agent and review

Own the LangGraph workflow, planning agent, coverage checks, saved state and approval screens. Hand C an approved plan.

CLesson agent and export

Own lesson generation, critique/revision tools, editing and LMS packaging. Give D approved slides and narration scripts.

DVideo and workflow evaluation

Own pretrained Qwen serving, narration, video and agent benchmarks. Coordinate GPU use and local execution logs.

Shared routine: integrate and demo every Friday. Everyone contributes tests, documentation and quality reviews; agree interfaces early so the four parts connect.

What we will hand over

  • A local prototype and sample course: syllabus, lessons, editable slides, exercises, video and LMS package.
  • A baseline-versus-agentic workflow evaluation report using pretrained models.
  • Code, tests, API and deployment guides, final presentation and demonstration.

How we will judge success

Use the same model, sources and rubric across repeated runs. Measure source support, coverage, teaching quality, readability, reviewer edits, time, model calls and GPU memory. Test approval/resume and offline operation.

Scope: pretrained models; no training or fine-tuning deliverable. Avatars, extra languages and SCORM 2004 remain optional.

How documents become a course

Qwen chooses whether to search again, revise a draft or request review based on evidence and critique. LangGraph limits those choices and preserves progress. Instructor approval is required before rendering and packaging. A–D match the team workstreams.
