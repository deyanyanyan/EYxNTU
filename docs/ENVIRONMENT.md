# Environment variables

Single source: the root `.env` (generated by `scripts/gen_env.py` from `.env.example`).
Docker compose passes it to every service; running the API directly also reads it.
`apps/api/app/config.py` validates required values at startup and refuses placeholders.

| Variable | Used by | cpu | gpu | Notes |
|---|---|---|---|---|
| `COMPOSE_PROFILES` | compose | `cpu` | `gpu` | Selects Ollama vs vLLM service. |
| `POSTGRES_USER/PASSWORD/DB/PORT` | postgres | ✓ | ✓ | `gen_env.py` randomises the password. |
| `DATABASE_URL` | api, worker | ✓ | ✓ | `postgresql+psycopg://…@postgres:5432/lms` inside compose; use `localhost` when running the API on the host. |
| `SECRET_KEY` | api | ✓ | ✓ | ≥32 chars; JWT signing. Rotating it logs everyone out. |
| `JWT_ALGORITHM`, `ACCESS_TOKEN_EXPIRE_MINUTES` | api | ✓ | ✓ | Defaults HS256 / 480. |
| `DEFAULT_ADMIN_EMAIL/PASSWORD/NAME` | api | ✓ | ✓ | Only used when the `users` table is empty. |
| `LLM_BASE_URL` | api, worker | `http://ollama:11434/v1` | `http://inference:8000/v1` | Any OpenAI-compatible server. |
| `LLM_API_KEY` | api, worker | any string | any string | Local servers ignore it; the SDK requires a value. |
| `LLM_MODEL` | api, worker | `qwen2.5:7b-instruct` | `Qwen/Qwen3-32B-AWQ` or `lms-adapter` | Must match a model the server exposes. |
| `LLM_TEMPERATURE`, `LLM_MAX_TOKENS`, `LLM_TIMEOUT_SECONDS` | api, worker | ✓ | ✓ | Defaults 0.3 / 4096 / 300. |
| `EMBEDDING_MODEL` | api, worker | `BAAI/bge-m3` | same | Changing it requires a new migration (vector width) and a re-embed. |
| `EMBEDDING_DIM` | api, worker, alembic | 1024 | 1024 | Must equal the model's output size; checked at load. |
| `EMBEDDING_DEVICE` | api, worker | `cpu` | `cuda` | |
| `EMBEDDING_BATCH_SIZE` | worker | 32 | 128 | |
| `HF_HOME`, `HF_HUB_OFFLINE`, `TRANSFORMERS_OFFLINE` | api, worker, inference | ✓ | ✓ | Set offline flags to `1` once weights exist under `data/models/hf`. |
| `RAG_TOP_K`, `RAG_SIMILARITY_THRESHOLD` | api, worker | 6 / 0.45 | same | Cosine similarity; bge-m3 scores run lower than OpenAI embeddings, hence 0.45. |
| `CHUNK_SIZE`, `CHUNK_OVERLAP` | worker | 1500 / 300 | same | Characters. |
| `TTS_BASE_URL`, `TTS_VOICE`, `TTS_ENGINE` | worker, tts | piper | kokoro | See `services/tts/README.md`. |
| `DATA_DIR` | api, worker | `/data` | `/data` | Mounted from `./data`. |
| `MAX_UPLOAD_MB` | api | 200 | 200 | |
| `API_PORT`, `WEB_PORT` | compose | 8000 / 3000 | same | |
| `CORS_ORIGINS` | api | `http://localhost:3000` | your host | Comma-separated. |
| `NEXT_PUBLIC_API_URL` | web (build-time) | `http://localhost:8000` | your host | Baked into the bundle at `next build`; rebuild the web image when it changes. |
| `LOG_LEVEL` | api, worker | INFO | INFO | |
| `WORKER_POLL_SECONDS`, `WORKER_MAX_JOB_MINUTES` | worker | 2 / 120 | 2 / 240 | Stale running jobs are failed after the max. |
| `VLLM_MODEL`, `VLLM_MAX_MODEL_LEN`, `VLLM_GPU_MEMORY_UTILIZATION`, `VLLM_LORA_MODULES` | inference | – | ✓ | `VLLM_LORA_MODULES=name=/data/models/adapters/<dir>` |
| `PROMPTS_DIR` | api, worker | set by compose | set by compose | Optional override; auto-detected in the repo layout. |

## Running the API on the host (outside Docker)
```bash
cd apps/api
python -m venv .venv && . .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
export DATABASE_URL=postgresql+psycopg://lms:<pw>@localhost:5432/lms   # from .env
export DATA_DIR=../../data
alembic upgrade head
uvicorn app.main:app --reload
```
The other variables are read from the root `.env` automatically.
